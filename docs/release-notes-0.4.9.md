Fixes a memory leak in 0.4.8.

- **Memory leak near poison (#75):** in 0.4.8 the game kept reserving memory while Mario was near poison (the Wooded Kingdom, the Spewart fight) and never released it. After a few minutes it could stop with "out of host memory". Fixed.

If you are on 0.4.8, please update.

## Updating

Windows: download the zip below and extract it over your current folder (or use **Updates** in the menu). Linux / Steam Deck: download the AppImage below, or use **Updates** in the menu. Your game files, saves and settings stay.
